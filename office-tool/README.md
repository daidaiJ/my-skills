# 办公工具

文档处理全家桶，支持 Word、PDF、PowerPoint、Excel、EPUB 等格式。

| Skill | 用途 |
|-------|------|
| [docx](./docx/) | Word 文档创建、编辑、模板填写（.docx/.dotx） |
| [markdown-to-epub](./markdown-to-epub/) | Markdown 转 EPUB 电子书，支持 Kindle |
| [pdf](./pdf/) | PDF 读取、合并、拆分、表单填写、OCR、图片插入、表格创建；内置确定性脚本工具包（提取/合并/拆分/填表，详见 references/pdf-toolkit.md） |
| [pptx](./pptx/) | PowerPoint 演示文稿，含 193 个预置模板和 QA 工具链 |
| [xlsx](./xlsx/) | 电子表格处理，支持公式、图表、复杂表格填写 |
| [liteparse](./liteparse/) | 轻量 PDF 文本提取，本地处理无依赖 |

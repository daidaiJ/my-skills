# 学术科研

科研全流程辅助工具，覆盖文献检索、实验设计、统计分析、同行评审等环节。

| Skill | 用途 |
|-------|------|
| [citation-management](./citation-management/) | 学术引用管理：搜索论文、提取元数据、验证引用、生成 BibTeX |
| [experimental-design](./experimental-design/) | 实验设计：随机化、区组、因子、交叉等方案规划 |
| [exploratory-data-analysis](./exploratory-data-analysis/) | 探索性数据分析：200+ 数据格式自动检测与综合 EDA |
| [hypothesis-generation](./hypothesis-generation/) | 假说生成：从观察/数据出发构建可检验假说和验证实验 |
| [paper-lookup](./paper-lookup/) | 论文检索：跨 10 个学术 API 搜索论文、预印本和开放获取全文；内置论文写作流水线（来源整理→提纲→引用规划→分节写作→整稿修订→摘要，详见 references/paper-pipeline.md） |
| [deep-research](./deep-research/) | 深度研究：多轮研究方法论、状态文件跟踪、逐条引用，产出可验证的综合报告 |
| [peer-review](./peer-review/) | 同行评审：基于清单的结构化评审，涵盖方法学和报告标准 |
| [scholar-evaluation](./scholar-evaluation/) | 学术评估：多维度定量评分与可操作反馈 |
| [scientific-brainstorming](./scientific-brainstorming/) | 科研头脑风暴：跨学科创意探索与研究空白识别 |
| [scientific-critical-thinking](./scientific-critical-thinking/) | 科学批判性思维：评估证据质量，应用 GRADE 等分级框架 |
| [scientific-schematics](./scientific-schematics/) | 科学示意图：AI 生成出版级科学图表 |
| [scientific-visualization](./scientific-visualization/) | 科学可视化：面向 Nature/Science/Cell 的出版级图表 |
| [statistical-analysis](./statistical-analysis/) | 统计分析：全流程引导式统计分析与 APA 格式报告 |
| [statistical-power](./statistical-power/) | 统计功效与样本量：研究规划的样本量和功效计算 |

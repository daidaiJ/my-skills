# Handoff

会话交接工具，将当前对话压缩为交接文档，供新 agent 继续工作。

## 使用

```
/handoff
/handoff 继续优化数据库查询性能
```

带参数时，参数描述下次会话的重点方向，交接文档会据此调整内容。

## 交接文档保存位置

文档保存在 **当前项目根目录** 下的 `.qwen/handoff/`，按日期命名：

```
.qwen/handoff/
├── 2026-06-15-db-refactor.md
├── 2026-06-16-perf-tuning.md
└── ...
```

不会保存到系统临时目录，跟着项目走，不会丢失。

## 在新会话中恢复进度

新开一个会话后，告诉 agent 读取交接文档：

```
读取 .qwen/handoff/2026-06-15-db-refactor.md，继续之前的工作
```

或者让 agent 自己找最新的：

```
读取 .qwen/handoff/ 下最新的交接文档，接着上次的进度继续
```

Agent 读取文档后会获得：
- 上次做了什么、当前状态
- 待办事项和卡点
- 关键决策和原因
- 建议调用的 skills（会自动执行）

## .gitignore

交接文档包含会话上下文，通常不应提交到仓库。在 `.gitignore` 中添加：

```
.qwen/handoff/
```

## 交接文档结构

生成的文档大致包含以下部分：

| 章节 | 内容 |
|------|------|
| 摘要 | 2-3 句话概括做了什么、当前状态 |
| 已完成 | 完成的具体事项 |
| 待办 / 卡点 | 未完成的事，卡在哪里 |
| 关键决策 | 做了什么选择、为什么 |
| 重要文件 | 涉及的文件路径（引用不复制） |
| Suggested skills | 推荐新 agent 调用的 skill |

# 中文 AI 写作模式

识别和消除中文 AI 生成文本的特征。

---

## 一、AI 高频词（禁用词表）

### 空洞大词

听起来很厉害，实际什么都没说。看到就删或换具体说法。

| 类型 | 词表 |
|------|------|
| 万能动词 | 推进、实现、建构、赋能、助力、打造、构建、深耕、优化、提升、深化、强化、细化、落实、统筹推进、多措并举 |
| 浮夸形容 | 白热化、质变、深远、不可或缺、至关重要、空前、史无前例、举世瞩目、波澜壮阔、气势磅礴 |
| 万能名词 | 方方面面、多维度、全方位、一体化、深层次、新高度、新台阶、新格局、新生态、新范式、闭环、颗粒度、抓手、势能 |

万能动词 + 空洞搭配示例——动词全是"推进""实现""建构"，看不到谁在做什么事：

| AI 味 | 人话 |
|------|------|
| 推进了数字化转型 | 公司去年上线了三套新系统 |
| 实现了质的飞跃 | 销量从 100 涨到了 500 |
| 构建了完善的体系 | 建了一套从招聘到考核的流程 |
| 深耕XX领域 | 在XX行业做了十年 |

### 连接词/过渡词

AI 用这些词制造"逻辑感"，实际是废话。删掉后句子照样成立。

| 禁用 | 替换方案 |
|------|---------|
| 值得注意的是 / 重要的是要记住 | 删掉，直接说内容 |
| 需要指出的是 | 同上 |
| 众所周知 | 同上，或改成具体出处 |
| 不言而喻 / 不言自明 | 删掉。如果真不言而喻就不用说 |
| 毋庸置疑 / 毫无疑问 | 删掉 |
| 事实上 / 实际上 | 删掉，或用"确实" |
| 综上所述 / 总而言之 | 删掉，直接说结论 |
| 由此可见 | 同上 |
| 换言之 | 删掉或用"也就是说" |
| 与此同时 | 删掉或用"同时" |
| 我们应该认识到 / 我们需要意识到 | 删掉，说教感。读者自己会判断 |

### 公文/宣传腔

训练数据中翻译文本和公文材料占比高，AI 分不清使用场景，混在一起输出。

| 禁用 | 问题 |
|------|------|
| 旨在 | 宣传稿用语 |
| 致力于 | 同上 |
| 历史悠久 | 空泛，改成具体年份 |
| 底蕴深厚 | 同上 |
| 蒸蒸日上 | 宣传腔 |
| 蓬勃发展 | 同上 |
| 享誉海内外 | 同上 |
| 风景如画 | 旅游宣传 |
| 得天独厚 | 同上 |
| 坐落于 | 用"在"就行 |

## 二、套话句式

### 开头套话

AI 用这些句式"暖机"。直接删掉，从具体内容开始。

| 禁用句式 | 人话替代 |
|---------|---------|
| 随着AI技术的飞速发展 | 直接说事情 |
| 在当今数字化浪潮下 | 删掉 |
| 人工智能正以前所未有的速度 | 删掉 |
| 近年来，XX领域取得了显著进展 | 改成具体数据或时间 |
| 在这个数字化时代 | 删掉 |
| 在XX的大背景下 | 删掉 |
| 从古至今，XX一直是… | 删掉或改成具体切入点 |

### 结尾套话

AI 用这些句式"收尾"。改成具体建议或直接结束。

| 禁用句式 | 人话替代 |
|---------|---------|
| 让我们拭目以待 | 删掉 |
| 未来已来，值得期待 | 改成具体下一步 |
| 这只是一个开始 | 删掉 |
| 我们将持续关注 | 删掉 |
| 相信在不久的将来 | 改成具体预期 |
| 总之，XX任重而道远 | 改成具体建议 |
| 总结来说… / 整体来看… | 删掉，直接说结论 |

### 模板化起手式

AI 偏爱的叙事套路，一眼识别。

| 模式 | 问题 |
|------|------|
| "那一刻…""那是一个特别的日子""我记得那天天气明媚" | 场景描写起手式，AI 万能开头 |
| 先写场景 → 再写心境 → 最后上升价值 | 固定连招，每篇都用 |
| "这让我想起了…" | 强行关联 |

## 三、句式结构问题

### 句型套壳（英文逻辑残留）

英文句式逻辑翻译到中文后的残留，是 AI 味最隐蔽的来源之一。以下是对照表，只列出没有独立小节展开的句式——有独立小节的见下文。

| 英文原型 | AI 味句式 | 人话 |
|---------|---------|------|
| In order to... | 为了……， | 想……，就要…… |
| If…then… | 如果说A，那么B | A，所以B |
| It's not until…that… | 直到A，才B | 人总是A了，才知道B |
| While… | 当……时 | 删掉"当…时"，直接写 |
| It is…that | 有一种A，就是B | A就是B |

### 否定平行结构（Negative Parallelisms）

句型："不仅是 X，更是 Y"、"不是 A，而是 B"、"不只是关于 X，而是关于 Y"。试图赋予平凡事物深刻意义。

> ❌ 这不仅是一幅画，更是一份记录她心理叙事的视觉文献。
> ✅ 这幅画记录了她的心理叙事。

> ❌ 重要的不是金钱，而是信任。
> ✅ 真正值钱的是信任。

> ❌ 不仅改变了观念，而且改变了生活。
> ✅ 改变的不只是观念，还有生活。

**修复：** 直接说 Y。删掉否定铺垫。

### 虚假范围（False Ranges）

句型："从 X 到 Y"。X 和 Y 往往风马牛不相及，或者从具体到抽象硬凑。

> ❌ 从解决问题的工具，到科学发现的艺术表达。
> ✅ 说清楚到底是什么范围，或者删掉这个句式。

**修复：** 如果 X 和 Y 不在同一个尺度上，删掉"从…到…"，分别说。

### 三段式排比（Rule of Three）

AI 强迫症：三个一组，节奏一致，像演讲稿。

> ❌ 提升了效率，降低了成本，优化了体验。
> ✅ 效率提上来了，成本也压下去了。体验？别提了，还是老样子。

> ❌ 它融合了历史的深度、文化的丰富性与现代的活力。
> ✅ 挑最重要的一个说，展开讲。

**修复：** 用两个，或一个展开说。打散节奏。

### 被动句/无主语

AI 回避明确主语，用被动句制造"客观感"。找出行为主体，用主动句重写。

| AI 味 | 人话 |
|------|------|
| 水平被提高了 | 团队提高了水平 |
| 标准被统一了 | 新规统一了标准 |
| 信号被释放了 | 央行释放了信号 |
| 问题被认为得到了解决 | 谁认为解决了？说出来 |

### 长复合句

AI 喜欢一个句子里塞 3-4 个分句，用逗号连起来。超过 35 字的句子，拆成两句。

> ❌ 通过智能化的文本生成能力，创作者可以在更短的时间内产出更多优质内容，同时保持较高的原创性和个人风格。
> ✅ AI 能帮你写得更快。但原创性和个人风格？得你自己加。

### 项目符号/列表过度

AI 喜欢用"1/2/3"列表或"首先、其次、再次"。只有描述对象平行独立时才用列表，叙事和递进用自然段落。

### "这""那"指代模糊

AI 常用"这""那"指代，但不明确对象。改成具体名词。

> ❌ 这体现了问题的复杂性。
> ✅ 关税和汇率的双重压力体现了问题的复杂性。

## 四、结构性问题

### 结构模板化，全文不推进

AI 文章每一段单看都通顺，但连起来读会发现全文没有推进。像议论文模板，不像人在说话。

| 模式 | 问题 |
|------|------|
| 第一段背景 → 第二段现象 → 第三段分析 → 第四段结论 | 固定四段式模板 |
| 每段正面两句 + 反面两句 + 不痛不痒的总结 | 两边不得罪，读完什么都记不住 |
| "一方面…另一方面" | 万能两头堵，回避判断 |
| "尽管…但仍然…" | 模板化转折 |
| "面临诸多挑战，但…" | 同上 |

**修复：** 有态度。你觉得好就说好，觉得垃圾就说垃圾。读者关注你不是因为你能客观，是因为你有判断。

### 金句空洞化

AI 生成的"金句"看似高屋建瓴，实际什么也没说。好的语言指向语言之外的世界，AI 的语言只指向更精美的语言。

> ❌ 它不是作者，而是你思想的探伤仪。
> ❌ 内化这些原则，你就能拨开生命中的迷雾。
> ✅ 直接说你做了什么、发现了什么、改变了什么。

### 模糊归因（Weasel Words）

AI 把观点归给模糊的权威，不说具体来源。制造有来源的假象。

| AI 味 | 人话 |
|------|------|
| 专家表示 | 哪个专家？出处在哪？ |
| 业内人士指出 | 具体谁？ |
| 有分析认为 | 哪篇分析？ |
| 据了解 | 谁了解的？ |
| 相关人士透露 | 谁？ |
| 研究表明 | 哪个研究？ |
| 批评者认为 | 谁？ |
| 观察家指出 | 谁？ |

## 五、节奏问题

### 句子节奏单一

每个段落差不多长，每个句子差不多复杂度。像一首只有一种节拍的歌，听 10 秒就困。

**修复：**
- 长段落后跟短段落
- 长句后跟短句（"真的。""就这么简单。"）
- 连续三句结构相同时，打散一个
- 手机屏幕上超过 5 行的段落拆开
- 句子长度变化能强调重点、控制节奏、引导注意力

## 六、检查清单

中文文本发布前逐项检查：

- [ ] 有没有禁用词表中的空洞大词？
- [ ] 开头有没有"随着…的发展"这类套话？
- [ ] 结尾有没有"值得期待""拭目以待"？
- [ ] 有没有"一方面…另一方面"两头堵？
- [ ] 超过 35 字的长句拆了吗？
- [ ] 被动句改主动了吗？主语明确了吗？
- [ ] 万能动词（推进、实现、建构）换具体动词了吗？
- [ ] 排比三连打散了吗？
- [ ] "专家表示""据了解"有具体出处吗？
- [ ] 连续三句结构相同？打散。
- [ ] 有你自己的判断和态度吗？
- [ ] 有具体数字、场景、经历吗？

# 简明技术中文 · 受控词表

四部分：禁用词与替换、选词表（一个意义一个词）、一词一义限定、行业黑话。

用法：

- 表里的替换建议是首选，不是唯一正确写法。同义可选时选表里的。
- 技术术语（`max_connections`、S1000D、OAuth）不受本表限制，按行业通行写法保留。
- 界面上的原文、报错原文、引用原文不按本表改写。

## 一、禁用词与替换

| 不用 | 用 |
| --- | --- |
| 登陆 | 登录 |
| 帐号 | 账号 |
| 缺省、预设 | 默认 |
| 单击、点按、按下 | 点击 |
| 键入、填入、录入 | 输入 |
| 删掉、去掉、移除、干掉 | 删除 |
| 登出、注销 | 退出登录 |
| 报错（名词） | 错误 |
| 入参、出参、形参、实参（未定义时） | 参数、返回值 |
| 挂掉、崩了、死掉 | 失败、停止运行 |
| 跑一下、跑一遍 | 运行 |
| 看一下、瞅一眼 | 查看 |
| 搞定、弄好 | 完成 |
| 弄、搞、处理一下 | 写出具体动作（设置、修改、执行） |
| 坑、踩坑、大坑 | 缺陷、问题、陷阱 |
| 丝滑、起飞、拉满、拉胯 | 流畅、达到上限、性能不足 |
| 一键、极致、秒杀、赋能式 | 写出具体能力（一次调用即可完成） |
| 进行 + 动词（进行修改） | 直接用动词（修改） |
| 加以、予以、作出 + 动词 | 直接用动词 |
| 做一次检查、完成一次同步 | 检查、同步 |

| 尽快、及时、尽早 | 具体时限（30 分钟内、当天） |
| 很、非常、比较、较为、大量、少量 | 具体数值，或删除 |
| 相关、相应、某些、其他 | 写出具体对象 |
| 等等、等（开放列举） | 列全，或「包括 N 种：A、B、C」 |
| 一下（检查一下） | 删除（检查） |
| 的话（如果失败的话） | 删除（如果失败） |

| 不得、不准、不可以 | 禁止 |
| 尽量、尽可能、酌情、视情况 | 写出触发条件与结果 |
| 由于、鉴于、考虑到 | 因为（描述句），或直接写条件 |
| 首先、然后、接着、最后（正文串步骤时） | 编号列表 |
| 综上所述、值得注意的是、需要指出的是 | 删除 |
| 我们将、我们可以看到、下面介绍 | 删除 |

## 三、一词一义限定

左列的词只保留右列的意义。超出这个意义时，换右列给的词。

| 词 | 只用于 | 其他意义改用 |
| --- | --- | --- |
| 打开 | 文件、窗口、页面、连接、端口 | 功能用「启用」，程序用「启动」 |
| 关闭 | 文件、窗口、页面、连接 | 功能用「停用」，程序用「停止」 |
| 可以 | 允许（你可以删除这个文件） | 能力用「支持」 |
| 支持 | 能力（支持 3 种格式） | 允许用「可以」 |
| 问题 | 疑问 | 故障、错误、缺陷 |
| 更新 | 数据和内容 | 版本用「升级」 |
| 接口 | 程序之间的调用契约 | 人机界面用「界面」 |
| 页面 | 浏览器或应用里的一屏 | 界面用「界面」 |
| 删除 | 数据、文件、配置项 | 软件用「卸载」，服务用「下线」 |
| 挂载 | 文件系统 | 等待用「等待」 |
| 挂起 | 进程状态 | 服务暂停用「暂停」 |
| 部署 | 把程序安装到环境 | 对外提供新版本用「发布」，启用新版本用「上线」 |
| 参数 | 函数或接口的输入 | 配置里的项用「配置项」 |
| 字段 | 数据结构或数据库表的列 | 界面的输入用「输入框」 |
| 缓存 | 数据的临时存储 | 记住用「保留」 |
| 同步 | 两处数据一致 | 通知用「通知」 |
| 修复 | 缺陷 | 数据用「恢复」 |
| 收敛 | 算法和数值 | 沟通场景写「达成一致」 |
| 脚手架 | 生成项目初始结构的工具 | 建筑结构按原义 |
| 对齐 | 数值、边界、格式 | 沟通场景写「确认」 |
| 复盘 | 事后回顾 | 建议写「回顾」 |
| 链路 | 调用链、请求路径 | 写具体的调用链 |

## 四、行业黑话

不说明具体动作。写出具体的对象和动作。

| 不用 | 用 |
| --- | --- |
| 赋能 | 提供接口、提供数据、培训 |
| 抓手 | 写出具体做法 |
| 闭环 | 写出流程的起点和终点 |
| 拉通、打通 | 连接、调用、共享 |
| 沉淀 | 写入、记录、归档 |
| 痛点 | 写出具体问题 |
| 对标 | 与 X 对比 |
| 打法、组合拳 | 写出具体步骤 |
| 颗粒度 | 粒度、精度、层级 |
| 底层逻辑、顶层设计 | 写出具体机制或方案 |
| 生态、势能、心智、体感 | 写出具体对象或数值 |
| 方法论 | 方法、步骤 |
| 降维打击、护城河、飞轮 | 写出具体优势或机制 |
